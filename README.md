# Urban Pulse – Smart City Mobility Intelligence Platform

## Project Overview
Urban Pulse is a Smart City Mobility Intelligence Platform developed as part of the Infosys Springboard Internship. The project integrates multiple transportation and environmental datasets to analyze urban mobility, transit performance, weather impact, road safety, and demographic trends through interactive Power BI dashboards. :contentReference[oaicite:0]{index=0}

## Datasets Used
- Taxi Trips
- Public Transit (GTFS)
- Weather Data
- Motor Vehicle Collisions
- Demographics

> **Location:** India  

## Tech Stack
- Power BI
- Power Query
- Microsoft Excel / CSV
- GTFS Data
- APIs (Weather & Transit)

## Features
- Data Cleaning & ETL
- Star Schema Data Model
- Interactive Dashboards
- Mobility Analytics
- Weather Impact Analysis
- Transit Performance Analysis
- Road Safety Insights
